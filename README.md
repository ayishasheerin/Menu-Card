# 🍽️ Al Qamar – Arabian Cuisine

Al Qamar is a simple and elegant Arabian cuisine restaurant menu website created using HTML and CSS.

The website showcases popular Arabian dishes with images, descriptions, Order Now buttons, and a Contact Us section.

## 🌟 Features

- 🍛 Arabian cuisine restaurant menu
- 🥘 Different food items with images and descriptions
- 🛒 Order Now buttons
- 📞 Contact Us section
- 📝 Contact form with Name, Age, and Email
- 🔗 Navigation links for Home, Recipe, and Contact
- 🎨 Simple dark-themed restaurant design

## 🍴 Menu Items

The website includes:

- Chicken Mandi
- Chicken Shawarma
- Tandoori
- Kunafa

## 🛠️ Technologies Used

- HTML
- CSS
